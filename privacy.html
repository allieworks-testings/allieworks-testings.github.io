Privacy Policy

Last updated: September 2026

Applies to: Allieworks Devtools (Google Workspace Add-on for Docs, Slides, Sheets, and Forms)

1. Information the Add-on Accesses

Allieworks Devtools is a Google Workspace Add-on that runs entirely inside Google Docs, Slides, Sheets, and Forms via the Google Apps Script platform. It accesses only the document, presentation, spreadsheet, or form you are actively working in, and only the specific properties needed to display or edit at your request — for example, selected object IDs, element position/rotation in Slides, active cell values in Sheets, or item titles in Forms. The add-on does not access your Google Drive, Gmail, Calendar, or any other Google service beyond the document type it's installed in.

2. How Your Information Is Used

All data the add-on reads or edits is used solely to power the functionality you directly invoke — for example, displaying the currently selected element's properties in the Dev Panel, or applying a position/rotation/value change you submitted through it. Nothing is used for analytics, advertising, or profiling.

3. No Third-Party or AI/ML Data Sharing

Allieworks Devtools does not use, integrate with, or transmit data to any third-party service, including any AI/ML models or platforms. All processing happens locally within Google's own Apps Script execution environment, using Google's built-in Docs/Slides/Sheets/Forms services. No document content, selection data, or user information is ever sent to Allieworks-operated servers or any external party.

Limited Use compliance statement: The use of raw or derived user data received from Google Workspace APIs by Allieworks Devtools adheres to the Google API Services User Data Policy, including the Limited Use requirements. No Workspace user data is used, transferred, or sold to train or improve any machine learning or artificial intelligence model, generalized or otherwise.

4. Data Storage

Allieworks Devtools does not operate its own backend server or database. It does not store, log, or retain any document content, selections, or user data outside of the Google Workspace file you're actively editing. Any changes you make through the add-on (e.g. editing a cell value or renaming a sheet) are written directly to your own Google file via Google's APIs, the same as if you had made the edit manually.

5. Authentication & Permissions

Access is governed entirely by Google's own OAuth consent screen at install time. Allieworks Devtools does not maintain its own login system, session tokens, or local storage of credentials — all authentication and permission handling is managed by Google.

6. Changes to This Policy

We may update this Privacy Policy from time to time. Continued use of Allieworks Devtools after any update constitutes acceptance of the revised policy. Material changes will be reflected in the "Last updated" date above.

7. Contact

Questions about this policy can be directed to allie@melo.cafe.
